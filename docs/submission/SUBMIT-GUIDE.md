## 二、两个链接怎么来（这是唯一需要你上网操作的部分）

### 链接 A：演示视频 → B 站

1. 打开 bilibili.com，登录，点右上角「投稿」→「视频投稿」。
2. 上传 `03-demo-video.mp4`（约 19 MB，几分钟内转码完成）。
3. 标题建议：`Nexus Decision Arena · 省赛演示（AI 决策评审与质询沙盘）`；
   简介里放 GitHub 地址；分区选「科技 · 计算机技术」。
4. **可见性必须选「公开」**，不要选「仅自己可见」，也不要加「充电专属」。
5. 审核通过后，复制形如 `https://www.bilibili.com/video/BV1xx411c7mD` 的地址——
   **这个才是要填进表单的「演示视频地址」**。

### 链接 B：完整作品文件 → 网盘

1. 把 `Nexus-Decision-Arena-submission.zip` 传到百度网盘 / 夸克网盘 / 阿里云盘任一。
2. 生成分享链接时勾选「**长期有效**」，并设置提取码（四位即可，记下来）。
3. 复制「链接 + 提取码」两段——表单那一栏要能让人凭它下载到东西。
4. 传完自己先在无痕窗口试下载一次，确认不是「仅自己可见」。

## 三、表单每一栏填什么

按你贴出来的顺序对照（表单原文若是措辞不同，按同一含义对应）：

| 表单栏目 | 填什么 | 备注 |
| --- | --- | --- |
| 1. UID | 你在赛事平台的账号 UID | 登录后在「个人中心 / 我的资料」里能看到的那串编号；找不到就问赛事群，别拿昵称顶替 |
| 2. 姓名 / 学校 / 组别 | 选手实名、学校、赛道组别 | 本赛道是**个人赛**，以个人为单位；指导教师非强制 |
| 3. 完整作品文件链接 | 链接 B（网盘链接 + 提取码） | 建议粘贴成 `https://…  提取码：abcd` 一行 |
| 4. 代码仓库地址 | `https://gitee.com/lost666666/nexus-decision-arena` 或 `https://github.com/LOST-123456/nexus-decision-arena` | 二选一即可，两个都公开，`main` 指同一个提交 |
| 5. 演示视频地址 | 链接 A（B 站视频页地址） | **不要填网盘地址** |
| 6. 作品介绍文档 | 上传 `01-project-intro.pdf` | 8 页，对应官网那 7 项要求 |

## 四、提交前的自查（照着勾，别凭印象）

- [ ] 无痕窗口打开链接 A：**不用登录就能播放**，声音正常、字幕清楚、能拖到最后。
- [ ] 无痕窗口打开链接 B：**不用登录就能看到文件**，输入提取码能下载，解压出 `00-README.txt`。
- [ ] 无痕窗口打开仓库地址：**不用登录就能浏览**，能看到 139 个提交、`main` 分支、README 正常渲染。
- [ ] 表单里没有把网盘链接填进「演示视频地址」。
- [ ] 上传的 `01-project-intro.pdf` 打开是 8 页，不是空白或半页。
- [ ] 记下提交成功后的截图或回执编号（只提交一次，出了争议这是唯一凭据）。

## 五、这些事我不替你做、也不该由我做

- UID、实名、学校、手机号这类**个人身份信息**只有你能填；
- B 站与网盘的账号、验证码、实名认证只有你能过；
- 「提交」这个动作不可撤销，最后一下必须你自己按。

## 六、如果链接失效了

网盘链接过期或被和谐、B 站视频被下架，都属于「材料还在但评审拿不到」。
截止前每隔几天用无痕窗口点一次；若已失效，重新生成链接并**在截止前重新提交**
（注意：每人只能提交一次，重新提交前先确认平台是否允许覆盖，不允许就只能靠第一次选对）。
